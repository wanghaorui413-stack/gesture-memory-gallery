# 秋招包装方案

## 推荐项目名称

手势驱动的 3D 交互式记忆相册

英文项目名可以写为 Gesture Memory Gallery。

## 一句话介绍

基于 Three.js 和 MediaPipe 实现一个浏览器端 3D 交互相册，支持照片上传、本地持久化、粒子化场景渲染、手势切换视图、捏合聚焦照片和滑动旋转浏览。

## 简历写法：技术/前端方向

**手势驱动的 3D 交互式记忆相册 | Three.js / MediaPipe / Vite**

- 基于 Three.js 搭建 3D 粒子场景，将蛋糕主体、蜡烛、火焰、彩纸和照片抽象为统一 Particle 对象，并通过 CAKE / SCATTER / FOCUS 三种状态管理目标位置、缩放和旋转动效。
- 接入 MediaPipe HandLandmarker 实现浏览器端手势识别，设计左手开合切换场景、右手捏合聚焦照片、横向滑动旋转浏览等交互逻辑。
- 实现多图上传、Canvas 压缩、localStorage 本地持久化和清空机制，使用户可自定义记忆照片，并避免服务端存储隐私风险。

## 简历写法：供应链/运营/采购方向

**个人数字化作品：手势交互式 3D Web 小应用**

- 独立完成一个交互式 3D Web 小应用，从用户场景出发拆解功能需求，并将复杂体验拆分为视觉渲染、手势识别、图片管理和本地存储模块。
- 通过快速原型方式验证个性化展示、非鼠标交互和本地隐私存储方案，体现数字化工具理解、产品意识和结构化问题拆解能力。

## 面试讲法

最初这是一个私人祝福场景，但我没有把它做成普通静态页面，而是拆成三个体验目标：仪式感、个性化和非鼠标交互。技术实现上，我用 Three.js 搭建 3D 场景，把不同视觉元素统一抽象成粒子对象；用 MediaPipe 在浏览器端识别手势；用 localStorage 保存用户上传的照片。

项目难点主要在实时交互的稳定性。手势识别会有抖动，所以我设计了阈值和状态管理：比如捏合距离小于阈值进入照片聚焦，松开后回到原模式；横向滑动只接收一个方向的有效位移，用衰减速度驱动旋转，减少误触。

如果面试岗位偏业务，我会把这个项目作为补充案例，不会把它包装成供应链项目。它更适合说明我能把一个模糊需求拆解成可执行功能，并快速做出可运行原型。

## 可继续优化的点

- 增加性能面板，记录粒子数量、平均帧率和加载耗时。
- 增加无摄像头 fallback，让鼠标和触控也能完成核心交互。
- 增加 GitHub Pages 部署，让项目可以直接通过链接演示。
- 增加截图或 GIF，提升作品集可读性。
